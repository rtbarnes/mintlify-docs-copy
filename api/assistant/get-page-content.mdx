## Rate limits

The same limits apply to all assistant API endpoints, including [Create assistant message](/api/assistant/create-assistant-message-v2) and [Search documentation](/api/assistant/search):

- 10,000 requests per Mintlify organization per hour
- 10,000 requests per IP per day
