## Rate limits

The same limits apply to all assistant API endpoints, including [Create assistant message](/api/assistant/create-assistant-message-v2) and [Get page content](/api/assistant/get-page-content):

- 10,000 requests per Mintlify organization per hour
- 10,000 requests per IP per day
